# Elfs & Orcs Tower Defense

Five races. One war. Pick your banner.

**Play: https://jumphp.net/elfs-orcs-tower-defense**

Made with [JumPHP](https://github.com/davidnurdin/jumPhp): retro games in PHP, on the desktop and in the browser.
The game is in `games/elfs-orcs-tower-defense/`.

```bash
bin/jumphp install elfs-orcs-tower-defense    # dependencies (everything runs in Docker)
bin/jumphp run elfs-orcs-tower-defense        # play on the desktop
bin/jumphp test elfs-orcs-tower-defense       # checks + a headless demo
```
