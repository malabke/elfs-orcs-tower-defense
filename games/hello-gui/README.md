# Hello GUI

A graphic app written in PHP with JumPHP: its window is a form made in the JumPHP IDE's visual editor
(`forms/MainForm.form.yaml`), drawn by `JumPHP\Gui` (no HTML), the same on Linux, Windows, macOS, phones and the web.

    bin/jumphp run hello-gui      # the app
    bin/jumphp test hello-gui     # its tests
