# hello-cli

A JumPHP CLI app: commands and a full-screen screen in the terminal (Symfony Console + symfony/tui).

```bash
bin/jumphp install hello-cli
bin/jumphp run hello-cli                 # the full-screen screen (arrows, Enter, a, d, q)
bin/jumphp run hello-cli add "Buy milk"  # a command; list-tasks, done 1, --help
bin/jumphp test hello-cli
bin/jumphp export:standalone hello-cli --linux --windows --macos
```
