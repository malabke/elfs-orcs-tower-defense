# hello-desktop

A JumPHP desktop app: native windows whose pages are HTML / CSS / JS, driven by PHP (Tauri).

```bash
bin/jumphp app:run hello-desktop       # a window on your screen
bin/jumphp app:test hello-desktop      # lint + phpunit + the app for real on a virtual screen
bin/jumphp app:shot hello-desktop      # var/screenshots/app.png
bin/jumphp app:export hello-desktop    # dist/standalone/hello-desktop-linux-x86_64: the app for Linux, one file to give
```

See `docs/tauri.md` of JumPHP.
