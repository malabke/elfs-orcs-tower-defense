# JumPHP IDE

The desktop app of the JumPHP IDE: edit your JumPHP games and apps with PHP code intelligence, Git, runs and tests, and a
visual HTML editor. The same IDE runs on jumphp.net/ide. Documentation: [docs/ide.md](../../docs/ide.md).

```bash
bin/jumphp install ide
bin/jumphp app:export ide        # dist/standalone/ide-linux-x86_64
./games/ide/dist/standalone/ide-linux-x86_64
```
