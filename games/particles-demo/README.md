# particles-demo

Jeu JumPHP. Depuis la racine du dépôt :

```bash
bin/jumphp install particles-demo   # dépendances
bin/jumphp run particles-demo       # jouer sur le bureau
bin/jumphp test particles-demo      # vérifications + test automatique sans écran
bin/jumphp build particles-demo     # version navigateur -> dist/web
bin/jumphp serve particles-demo     # http://localhost:8080
```

Commandes : flèches / WASD pour bouger, Espace pour sauter, Échap pour la pause.
