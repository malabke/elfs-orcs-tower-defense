# Effects

Screen effects for JumPHP games (`jumphp/effects`): transitions (fade, wipes, iris, blinds, dissolve), a flash, a vignette, easing curves.
Documentation: `doc/index.md`; samples: `doc/samples/` (`bin/jumphp extension:add <game> jumphp/effects` copies both into your game).
Example game: `games/effects-demo`.
